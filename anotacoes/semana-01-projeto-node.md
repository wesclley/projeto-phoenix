# Inicialização de um projeto Node.js

## O que o npm init -y faz?
Inicializa um projeto Node.js criando o arquivo package.json com as configurações padrão.

## Para que serve o package.json?
É um painel de controle que gerencia as dependencias que são as bibliotecas, armazena metadados, modulos e scripts.

## Qual a diferença entre node index.js e npm start?
o node index.js executa direto o arquivo especifico e o npm start executa do script dentro do package.json.
## O que são módulos?
São arquivos e bibliotecas
## Por que separar o código em arquivos?
Para cada arquivo atuar em uma parte do projeto.
