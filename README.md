# Projeto Phoenix

- **Objetivo:** evolução para Backend Engineer
- **Stack principal:** JavaScript, Node.js, MongoDB e Mongoose
- **Início:** agosto de 2026
- **Carga de estudos:** 2 horas por dia
- **Metodologia:** teoria, prática, arquitetura, desafio e revisão

## Portfólio de integrações

[Conheça os estudos de caso de integrações profissionais](projetos/portfolio-integracoes/README.md): 10 casos organizados a partir de 13 workflows desenvolvidos no contexto ChatGuru + n8n da equipe, envolvendo CRMs, captação de leads, cobrança, agenda de saúde, atendimento educacional e logística.

Os casos apresentam problemas de negócio, soluções e decisões técnicas com informações de clientes anonimizadas. Esta seção reúne experiência profissional; os exercícios de formação continuam em `estudos/`.
